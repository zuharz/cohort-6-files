# Практика второй встречи

Учебный комплект AI Sandbox: создание навыка greet, сверка двух Excel-файлов и домашняя работа с новым реестром. Данные синтетические, реальные чеки и личные данные не используются.

## С чего начать

1. На [главной странице репозитория](https://github.com/zuharz/cohort-6-files) нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте папку `session-2` из распакованного архива как отдельный проект в Codex. Все чаты практики создавайте внутри этого проекта.
3. Проверьте, что прямо в этой папке лежат три Excel-файла и `reconciliation_rules.md`.
4. Откройте [промпты практики](practice_prompts.md) и начните с G1. Копируйте в чат содержимое блоков по порядку.

| Файл | Для чего нужен |
| --- | --- |
| `receipts.xlsx` | Таблица чеков, источник для сверки |
| `register_a.xlsx` | Реестр для практики на занятии |
| `register_b.xlsx` | Новый реестр для домашней работы |
| [reconciliation_rules.md](reconciliation_rules.md) | Общие правила сверки |
| [practice_prompts.md](practice_prompts.md) | Запросы для занятия и домашней работы |

Сначала создайте и вызовите `greet`, затем выполните сверку A и сохраните процесс в навык. Для домашней работы примените этот навык к реестру B, проверьте результат по исходным таблицам и исправьте отдельную копию реестра после собственного подтверждения. Подробный порядок и состав сдачи находятся в промптах.

Сохраняйте исходные Excel-файлы без изменений. Имена файлов не переименовывайте: они используются в запросах. Фотографии чеков для этой практики не нужны, работаем с готовыми таблицами.
