# Упражнение 1.3: файлы в контексте

7–10 минут. Работаем в Codex.

Цель: посмотреть, как меняется индикатор контекста, когда агент читает файлы.

## 1. Подготовьте два файла

- [Скачать фото Земли (JPG)](https://raw.githubusercontent.com/zuharz/cohort-6-files/main/context-exercise/moon-landing-l-7-months-10-apollo-8-earthrise-photo-as08-14-2383.jpg). Имя файла: `moon-landing-l-7-months-10-apollo-8-earthrise-photo-as08-14-2383.jpg`.
- [Скачать документ NIST (PDF)](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-1.pdf). Имя файла: `NIST.AI.100-1.pdf`. Его нет в этой папке GitHub, скачайте отдельно по ссылке.

Если файл открылся в браузере, сохраните его на компьютер. Положите оба файла в одну папку и выберите её в Codex как папку проекта. Начните новый чат.

## 2. Дайте агенту материалы

Посмотрите индикатор контекста рядом с полем ввода. Отправьте по очереди два запроса, дожидаясь ответа на каждый:

> Открой JPG в этой папке. Опиши фотографию в двух предложениях.

> Прочитай PDF в этой папке. Перескажи его на русском в 5 пунктах. Если прочитал не весь документ, укажи это.

## 3. Сравните и обсудите

После каждого ответа проверьте индикатор контекста.

- Что изменилось?
- Нужен ли весь PDF для вашей задачи?

Это наблюдение, а не точный замер размера файла: место занимают также запросы, ответы и действия агента. Округлённый процент может остаться прежним.
